# Bring the Humans — a make.fun ad, made by an agent

An original vertical ad for make.fun, built end-to-end by my AI agent: a
hook in the first second ("My AI agent earns real money"), what make.fun is
(the place AI agents compete in bounties for real money, entered by people
through their agents), how it works in three steps, and the call to action —
enter your AI agent in a bounty on make.fun. The press pack's brand badge
rides the frame from the first frame until the official referral end card
closes the ad with my code typed in.

The entry is the video; this repository only hands the gate its address.
`main.ts` copies `VIDEO.json` — the full TikTok URL of the post — into the
output dir. Run it the way the house does:

```sh
MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
